# PP 交互演示

固件网站的 `/pp-demo/` 是 PC 操作台。设备屏幕使用 PA-Terminal 的布局和显示素材；本次对照的固件版本及源码指纹见[交互对照记录](../public/pp-demo/lab/parity.json)。
右侧页签控制对话样本、配网步骤和故障注入，并显示 [验收进度](pp-iteration.md)。切换页签保留当前模拟设备状态。

- **对话**提供一个场景选择器、模拟输入和按键说明。任务已接受后显示“送达后台结果”，长输入场景提供录音上限入口。
- **配网与配对**从已配对状态开始。模拟首次开机后依次显示热点配置和八位码表单。配对完成后可展开 PA 设备设置。
- **异常与调试**提供空输入、识别失败、断网和清缓存。电量、时间、RSSI、PA 状态和事件记录按需展开。

键盘使用空格或 Enter 代替 OK，方向键代替上、下。首次长按 200ms 进入收音，松开停止收音。
300ms 内第二次短按切换引导／排队。从其他页面长按上 650ms 回主页。在空闲主页长按上 3 秒立即熄屏，
松手后仍保持休眠。返回主页的那一次长按只执行返回。聊天和历史中长按下 650ms
跳到最新消息，离线时跳到最近缓存；松开停在该消息。播报时短按上、下每次调整 5，
短按 OK 结束本条播报，文字继续交付。超过录音时限进入确认页，默认丢弃，可以先翻看转写。
短按 OK 打开双列菜单，默认选中「任务消息」。子菜单使用单列，返回上级时保留原焦点。「声音与屏幕 → 屏幕亮度」用上下键实时预览，OK 保存，长按上回主页放弃调整。
休眠时屏幕熄灭并断开 PA。「电源与待机」中的「熄屏保持 Wi-Fi」默认开启，休眠时保留已有 Wi-Fi，掉线后等唤醒再连接。唤醒按键只负责唤醒。浏览器失焦会取消正在进行的按键手势。

## 显示与素材

`core/display.js` 使用原生 240×320 坐标。状态栏、分隔线、形象、正文、菜单、任务色、音量
反馈和页脚坐标对应固件 `main/ui.c`。文字分页使用 16／18 像素字形的实际字宽和行高。
`display/` 的字形位图来自固件两套中文字体和 LVGL 图标，形象来自固件 RGB565A8 资源。
原始屏幕像素随外壳一起缩放。Wi-Fi 由固件三档颜色表达，电池使用比例填充与居中数字，输入模式用固件
右下角的两个图标。回复、任务、图片和历史使用同一屏幕组件。

更新固件 UI 后，对照 `main/ui.c`、`main/main.c`、`main/navigation.c` 和
`main/terminal_model.c` 更新坐标及交互。字体或形象变化时可从已有的固件源和 LVGL 依赖导出素材。
导出脚本需要 Python 与 Pillow，浏览器直接使用生成后的静态资源。

```sh
python tools/export_demo_display.py /path/to/pa_terminal
```

`core/device-shell.js` 负责外壳、屏幕和侧键，`core/keys.js` 负责鼠标／键盘。
`model.js` 持有独立的模拟状态和请求版本，`demo.js` 将状态投影到固件屏幕和右侧面板。
`scenarios.js` 声明输入和回复，可附澄清、报告或一张本地合成缩略图。新增普通对话场景直接
加一项声明，沿用同一外壳和交互逻辑。硬件外观和字体许可分别随资源提供。

## 模拟边界

对话内容、声量、文字速度、PA 连接、设备状态和后台完成时间都是本地样本。页面不请求麦克风或
USB 权限，不连接 PA，也不产生模型或语音调用。配网密码留在页面内存，音量、亮度、模式和待机
偏好保存到浏览器。历史演示使用近期记录窗口，线上浏览不会淘汰近期缓存。字节显示是浏览器模拟
数据的占用，真机 Flash 分区和图片读写需要单独验收。

Wi-Fi 云配置最多五套。设备开机先尝试连接，离线期间每隔一分钟再试一批，每批最多三次。
失败后沿列表顺序接着尝试，连接成功便停止。PP 顶部图标在搜索期间脉动，批次间静止。
调试页可以制造离线状态。Wi-Fi 断开且已有网络配置时长按 OK 立即重试，当前正在尝试时忽略。「网络与配对」也可重试或进入重新配网。「PA 与维护」中的同步只应用发生变化的配置项。
由于语音与硬件时序使用合成样本，真机录音、输出、网络恢复和电源状态须按独立用例测试。

## 预览与检查

Compose 将源码直接挂载到 `/srv/pp-demo`，Nginx 通过 `/pp-demo/` 读取并设置
`no-store`。源码更新后刷新页面即可看到。外壳、屏幕和状态模型的回归可单独运行：

```sh
node --test tests/passport-demo.test.mjs
/home/macaulish/workspace/PersonalAgent/.venv/bin/python tests/verify_passport_demo.py
```

浏览器检查覆盖默认面板、屏幕尺寸和布局、模式保存、按住／释放、音量及停播、离线缓存、
缩略图、转写确认、任务结果和初次配对。可用 `--url` 指向本站的演示地址。
