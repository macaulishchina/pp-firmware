# PA-Terminal 0.2.1-preview.6

在固件中心选择此版本，通过 USB 更新。沿用 preview.5 的分区布局，保留已保存的 Wi-Fi、配对、设备偏好和历史缓存。

本版改进了短音频分块的播放、停播后再次录音、无线重连和深睡交接。音频硬件故障时仍可查看消息和设置。已通过固件构建、协议集成和浏览器交互检查，实际录播、无线和唤醒体验待真机验证。

## 刷机后验证

1. 开机后确认设备沿用原 Wi-Fi 和配对。播放一条语音回复，按 OK 停播，随后长按 OK 发起下一轮录音。
2. 提交一条测试消息后断开并恢复 Wi-Fi，查看原输入的回执及会话记录，确认无重复提交。
3. 空闲时从设置进入休眠，用按键唤醒。松开后再次操作，确认按键、显示和音频恢复。
