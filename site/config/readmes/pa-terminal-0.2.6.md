# PA-Terminal 0.2.6

改善弱网上传时的录音。录音开始时优先从已有内存预算中分配麦克风队列和 Flash 读写工作页。上传暂时停住，设备可以继续收音，把积压的音频存入临时 Flash，恢复后按顺序上传。松手后请等待转写。单次录音仍受原有时长限制。

设备确实无法再接收下一帧时，会提示「缓冲已满，上传已录部分」，保留已录内容供确认。缓存用于当前连接，完全断开后不会自动重发。

## 安装和验证

通过 USB 数据线连接 PP，在桌面 Chrome 或 Edge 打开固件中心，选择「PA-Terminal · 0.2.6」，点击「安装到 PP」。沿用 0.2.5 的分区，安装前会核对设备分区布局，保留 Wi-Fi、配对和历史记录。

已通过固件单元测试和合成语音集成测试。PassportSim 使用本版应用镜像，在延迟接收的场景中完成了录音、Flash 暂存、补传和转写。真机弱网表现待验收。可在此前容易出现提示的位置长按 OK，念一段约 15 秒的话，松开后核对第一句和最后一句是否都在。
