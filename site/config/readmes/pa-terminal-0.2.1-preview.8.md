# PA-Terminal 0.2.1-preview.8

在固件中心选择此版本，通过 USB 安装。沿用 preview.7 的分区布局，安装包不写配置分区；普通更新保留原 Wi-Fi、PA 配对和设备设置。请勿整片擦除或恢复出厂。

本版修复录音失败后反复出现收音中断、状态不匹配和语音忙的问题。音频发送暂时落后时，终端仍为结束和取消指令保留队列空间。配套 PA 修复会清理失败录音，终端显示一次对应原因，再回到可录音状态。

隔离验收已用实际固件注入语音识别超时，确认下一轮无需重连即可完成录音、转写和回复。实际麦克风、无线网络与云端识别的连续录音待真机验证。

## 刷机后验证

1. 重启后确认显示本版版本号，自动连接原 Wi-Fi 和 PA，保留原配对。
2. 按住 OK，说一句短句后松开，确认转写和回复正常。连续试三轮。
3. 回复播报时按 OK 停播，随后长按 OK 再说一句，确认下一轮正常转写。
4. 若自然出现一次识别失败，记下屏幕完整提示及时间。确认界面回到可录音状态，再试一次。
