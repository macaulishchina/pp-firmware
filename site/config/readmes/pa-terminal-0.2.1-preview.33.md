# PA-Terminal 0.2.1-preview.33

录音和播报共享 3 MiB 临时缓存，历史记录和离线预览共用 1 MiB。打开照片时先显示小预览，联网后按条带更新为高清图。高清流中断时可继续看已取得的预览。设备只缓存小图。

在电脑上用 Chrome 或 Edge 打开固件中心，连接 PP 并选择「安装到 PP」。升级期间保持 USB 连接。安装器核对设备分区、复制旧历史缓存并校验后才更新分区表，Wi-Fi 和配对配置保持原址。如果旧设备尚无独立临时缓存分区，请先通过维护者提供的 preview.32 过渡包升级。

已用 PassportSim 运行此固件并验证在线、离线和重连看图，真机待验收。安装后可翻看之前的图片、断网查看预览，并连续上翻历史记录。
