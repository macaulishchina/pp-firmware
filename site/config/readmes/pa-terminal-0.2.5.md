# PA-Terminal 0.2.5

修复长按 OK 开始录音时误报「请求未完成」的问题。关闭高清图片由图片页面处理，开始录音时已移除多余的旧图片指令。

播报在首次缓冲见底后，如果连续两段收到音频的速度都跟得上播放，设备可提早恢复播放。持续慢速或反复断流时，仍按原有策略积累缓冲。

## 安装与验证

用 USB 数据线连接 PP，在桌面 Chrome 或 Edge 的固件中心选择「PA-Terminal · 0.2.5」，点击「安装到 PP」。安装器先核对设备分区，布局兼容时保留 Wi‑Fi、配对和历史记录。

固件单元检查、PA 合成语音集成检查及 ESP-IDF 构建已通过，真机验收待完成。安装后可在「网络与配对 → PA 与维护 → 关于设备」核对版本，再长按 OK 说一句话，松开后核对转写及播报。
