# PA-Terminal 0.2.1-preview.10

在固件中心选择此版本，通过 USB 安装并保留设备配置。普通更新保留原 Wi-Fi、PA 配对、设备设置和已提交的离线缓存。

## 本版改动

- 录音直接将采样写入发送缓冲，减少中转占用。播报接收按帧长度申请缓冲，修复异常时混淆播放编号和连接编号的问题。
- 历史和缩略图共用缓冲和 Flash 缓存。内存紧张时，后台工作释放大缓冲，空闲后从原进度继续。缓存暂忙时保留已显示的历史。
- 串口 `pp.status` 增加缓冲峰值、分配失败和缓存统计，可对照重连或连续录放前后的内存表现。

ESP-IDF 构建、固件宿主测试和 PA 集成测试已通过。PassportSim 已验证录放、断线重录、断网重启后读取文字和缩略图，以及读取旧版缓存。实体设备的录放、Wi-Fi 重连和 Flash 与录音同时工作仍待验收。

## 刷机后验证

1. 在串口日志输入 `pp.status`，确认版本为 `0.2.1-preview.10`，并核对原 Wi-Fi 和配对可自动恢复。
2. 按住 OK 录音，检查开头和结尾。短按 OK 停播后马上再录一次。
3. 打开历史和缩略图，断网重启后再次查看。缓存接近满、正在写入时，重点检查录音开头是否完整。
