# PA-Terminal 0.2.1-preview.22

在固件中心选择该预览版，通过 USB 安装。按包内分区地址写入，跳过整片擦除即可保留原 Wi-Fi、PA 配对和本机设置。

## 本版改动

- 设置中新增「熄屏保持 Wi-Fi」，默认开启。熄屏后 PP 断开 PA，暂停业务心跳和搜寻，仅维持已连接的 Wi-Fi。热点断开后，等按键唤醒再搜寻。关闭此选项可使用深睡。
- 同一条回复使用一次连续播放。配套 PA 更新会提前合成下一段，清理播报文本中的空白和装饰格式，并对长句分段。播报失败时 PP 在状态栏提示，仍可查看原文。
- 图片支持分块高清显示。连翻多张时逐块接收和绘制，历史里仍可查看已缓存的离线预览。
- 改进设备维护菜单、等待回复提示和电量显示。聊天时长按下可跳到最新消息。

已通过构建、固件与浏览器回归、PA/Pi 集成和 PassportSim 模拟验收。iPhone 锁屏后热点的保持时间、待机功耗和实际听感待真机验证。

## 刷机后验证

1. 在串口日志输入 `pp.status`，确认版本为 `0.2.1-preview.22`。核对原 Wi-Fi 和配对能自动恢复。
2. 连接 iPhone 热点后锁屏，让 PP 熄屏。数分钟后按一次 OK，确认能否沿用 Wi-Fi 恢复 PA。
3. 配套 PA 更新后，试播多句回复、含链接或表情的回复和无标点长句，再试一次中途按 OK 停播。
