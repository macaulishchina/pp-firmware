# PA-Terminal 0.2.1

主页按上或下即可查看本机保存的最近三条已完成消息。联网和离线使用同一份历史记录，翻页和长按下跳到最新都直接从本机读取。长消息只显示已经缓存的部分。断网或重连时可以继续读当前页。

查看历史照片时先显示本地预览。在线时可按屏幕尺寸分块加载高清图，离线时可以翻看已缓存的缩略图。

## 安装

使用桌面 Chrome 或 Edge 打开固件中心，用 USB 连接 PP，选择「PA-Terminal · 0.2.1」，点击「安装到 PP」。安装期间保持 USB 连接。从 0.2.1-preview.33 升级沿用相同分区，保留 Wi-Fi、配对和历史缓存。如果旧设备尚无独立临时缓存分区，请先通过维护者提供的 preview.32 过渡包升级。

安装后可在「网络与配对 → PA 与维护 → 关于设备」查看固件版本。此版本真机待验收。
