# PA-Terminal 0.2.7-preview.1

修复连续收到多张图片时，部分离线预览没存下来的问题。新 PA 会等待 PP 确认上一张已写入，再发送下一张。正文可以先显示，图片预览随后补齐。

高清图条带使用独立的接收槽。普通消息集中到达时，正在查看的高清图仍能继续刷到最后一行。

## 安装与验证

用 USB 数据线连接 PP，在桌面 Chrome 或 Edge 的固件中心选择「PA-Terminal · 0.2.7-preview.1」，点击「安装到 PP」。安装器先核对分区布局，兼容时保留 Wi-Fi、配对和历史记录。逐张写入回执需要本版 PP 和配套 PA 插件。

已通过 24 张预览写入和高清全图压力测试、ESP-IDF 构建及合成语音集成检查。真机联网复测待完成。
