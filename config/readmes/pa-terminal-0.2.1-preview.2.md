# PA-Terminal 0.2.1-preview.2

修复重刷后设备保留旧 Wi-Fi、尚未配对时无法进入重新配网的问题。固件构建和模拟操作已通过，真机验收待完成。

## 保留配置更新

在固件中心选择本版本，用 USB 数据线连接 PP，点击 **安装到 PP**。网页按清单写入固件分段，保留 Wi-Fi、配对和本地设置所在的 NVS 分区。升级自 `0.2.1-preview.1` 时，引导程序和分区表与上一版相同。

## 重新配网

1. 未配对且已有 Wi-Fi 设置时，在设备上按 **OK** 打开配网确认。已配对时从 **设置 → 设备维护 → 重新配网** 进入。
2. 按上键或下键切换到确认，再按 **OK** 开启热点。手机连接屏幕显示的热点，在浏览器打开 `http://192.168.4.1`。
3. 填写 2.4 GHz Wi-Fi。当前 PA 局域网业务地址为 `https://110.0.0.82:8047`，外网地址为 `https://47.109.34.254:8047`。在「HTTPS 私有 CA」中粘贴[公开 CA 证书](https://110.0.0.82:9443/certs/pp-firmware-ca.crt)的完整 PEM 内容。
4. 保存后，如 PP 显示八位配对码，到 **PA 配置后台 → 插件设置 → AI Passport → 设备 → 配对新设备** 输入配对码。

取消确认或仅开启热点会保留原配置。提交热点页面后，设备按新的网络和 PA 地址连接。
