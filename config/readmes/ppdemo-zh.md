# PPDemo-Zh 0.2.0 中文版

PP 的独立中文硬件体验和质检固件，用于测试屏幕、按键、录放音、电量计、Wi-Fi、BLE、NVS、休眠唤醒、USB 和被动 NFC 标签。

**已通过主机检查、ESP-IDF 编译及镜像校验；真机待验收。** 发布可供你自行安装测试，不代表所有硬件已验证。

## 中文界面

屏幕菜单、测试动作、操作提示、人工评价和手机 Wi-Fi 配网页均为中文。
内置简体中文字形，不需要联网加载字体。USB 命令 `report`、JSON 的机器字段、
设备错误代码和蓝牙服务编号仍保留原文，方便定位问题与自动处理。
长报告自动滚动显示；功能、分区布局与英文版一致。
两个版本共用本机人工报告，切换语言不会主动清空结果。

## 按键

- 首页：上／下选项目，OK 进入；长按 OK 查看总报告。
- 测试：上／下选动作，OK 执行；长按 OK 停止并进入人工评价。
- 评价：上键“通过”，下键“不通过”，OK“未测试”。保存成功后回到首页。
- 报告：OK 向 USB 导出 JSON，长按 OK 返回。

程序不会根据驱动返回值自动标记 PASS。录音仅在 RAM，进入无线或重启会清除；报告和测试计数保存在独立 NVS 命名空间。

## 体验顺序

先屏幕、按键、USB，再音频、电池和存储，最后无线与休眠。

Wi-Fi 测试按 OK 后才开启，手机连接屏幕显示的临时热点，打开 http://192.168.4.1 配网。
凭据只保留在 RAM，180 秒或退出后关闭无线。获得 IP 只代表局域网连接，不证明互联网可用。

BLE 测试扫描 PP-DEMO；服务 FFF0，向 FFF1 写入 1～64 字节，读 FFF2 或订阅通知确认回显。
120 秒或退出后停止。此测试链路没有生产加密鉴权，不要发送隐私数据。

NFC 是被动标签，用手机读取；MCU 没有 NFC 读取接口。USB 是 Serial/JTAG，不是 USB 声卡。
电量计可能因硬件版本而缺失，不测充电电流或续航。深睡约 10 秒后重启唤醒，请释放按键。

## 安装与数据

目标为 ESP32-C3、8 MB Flash 的 FoloToy AI Passport。安装前确认设备，使用数据线连接电脑。

网页下载并校验全部三个镜像后再按地址写入，并核对设备返回的传输 MD5；不执行整片擦除。
启动区域、分区表和应用将被替换。已有分区布局或数据格式不一致时，不能保证数据仍可使用。

写入成功后请求重启，并进入串口日志。输入 `report` 加回车读取人工报告；屏幕和真实声音仍需你观察。
如写入中途断开，不会自动重做，请先重新连接并确认设备状态。

## 下载包与命令行

下载包只含三个镜像、公开说明和 SHA256 清单，不含本机配置、凭据或 ELF/MAP。

Windows 安装 Python 后可用以下命令（将 COM5 换成实际串口）：

```text
py -m pip install esptool==4.13.0
py -m esptool --chip esp32c3 --port COM5 write_flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 ppdemo.bin
py -m serial.tools.miniterm COM5 115200 --echo
```

串口输入 `report` 加回车，`Ctrl+]` 退出。重新刷写前关闭占用串口的其他程序。
