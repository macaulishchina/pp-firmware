# PA-Terminal 0.1.1

修复第一版连接中断：ESP32-C3 无 PSRAM，原固件在 TLS 握手期间内存不足。
本版按实际帧大小分配录音队列，USB 配置和网络接收按需申请缓冲，保留原有容量，
并显示更具体的网络错误。保留完整证书与服务器身份验证。

已在真实 PP 上刷写并确认连接 PA，原 Wi-Fi 和配对信息保留。真人语音、续航与完整体验仍待验收。

需要 PA 0.4.34 或兼容版本。通过 USB 更新，不执行整片擦除、不覆盖 NVS。
已有配置的设备更新后可以直接重连，无需重新填写 Wi-Fi 或重新配对。
首次使用则打开 [USB 配置页](/pp-setup.html)，写入 Wi-Fi、PA 配对文件和公开 CA。

按住 OK 讲话，松开发送；短按停播／打开菜单，双击切换引导与排队，上下键翻页。
默认空闲两分钟休眠，桌面使用可手动保持在线。PPDemo 两个版本仍独立保留。
