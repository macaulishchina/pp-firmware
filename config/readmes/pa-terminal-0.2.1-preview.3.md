# PA-Terminal 0.2.1-preview.3

配网页只需要填写 Wi-Fi 名称和密码。本版本内置 PA 的外网 HTTPS 地址 `https://47.109.34.254:8047` 和对应公开 CA。构建和模拟验收通过，真机验收待完成。

## 安装与配网

1. 在固件中心选择本版本，通过 USB 安装。刷写保留已保存的 Wi-Fi、配对和设备设置。已连接 PA 的设备可以直接使用。
2. 新设备按屏幕提示连接临时热点。需要换网或旧配置连不上时，从设备菜单进入 **重新配网**。未配对且已保存 Wi-Fi 时，在主页按 **OK** 打开配网确认。用上键或下键选确认，再按 **OK**。
3. 手机连接屏幕显示的热点，打开 `http://192.168.4.1`。填入 2.4 GHz Wi-Fi 的名称和密码，然后点击 **保存并连接**。设备会用固件预设的 PA 地址连接。
4. 如屏幕出现八位配对码，到 **PA 配置后台 → 插件设置 → AI Passport → 设备 → 配对新设备** 输入配对码。绑定后在 PP 上长按 **OK** 讲话，松开发送。
