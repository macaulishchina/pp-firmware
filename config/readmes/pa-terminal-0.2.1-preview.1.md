# PA-Terminal 0.2.1-preview.1

预览版，供安装体验与反馈。沿用当前 0.2.0 功能，重新构建预览版本标识；不宣称本预览镜像通过新增真机验收。

## 安装与连接正式 PA

1. 在固件中心选择本版本，通过浏览器 USB 安装。刷写保留 Wi-Fi 等 NVS 配置，不整片擦除。
2. 若设备仍连接原隔离测试服务：打开 **设置 → 设备维护 → 重新配网**，确认后连接 PP 屏幕上的热点，浏览器打开 `http://192.168.4.1`。
3. 填写 Wi-Fi，并将 PA 业务根地址设为 **http://47.109.34.254:8047**。不要使用 9443，也不要填写 WSS 路径。若处于同一局域网，也可以用 `http://110.0.0.82:8047`。
4. 联网后，PP 显示八位配对码。在 **PA 配置后台 → AI Passport** 输入配对码及设备名称，完成绑定。正式 PA 会建立独立 PP 会话，不继承合成测试聊天。

## 操作

长按 OK 讲话、松开发送；短按 OK 停播；播放时上下调整音量；双击 OK 切换引导／排队；长按上回主页。菜单可查看任务消息、设置和设备维护。

最近消息文字及缩略图采用有界 Flash 缓存：独立 512 KiB 分区，实际数据预算 256 KiB；不是无限历史离线保存。更新需要同时写分区表与应用，浏览器根据本版清单执行，不写 NVS。

## 服务与状态

配套 PA 0.4.35、AI Passport 插件 0.3.0／协议 2。业务使用 HTTP/WS 8047；HTTPS 9443 只用于固件网站。原有语音用量保护保持不变。重连速度及长期稳定性继续按日常使用反馈优化，本次不追加验收。

若无配对码而仍无法连接，可通过设备维护重新配网核对业务地址；不要重复刷写来代替改地址。
