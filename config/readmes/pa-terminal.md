# PA-Terminal 0.1.0 · 候选

用于 FoloToy AI Passport 的 PA 交互入口：中文界面、按住 OK 讲话、文字及语音回应、
独立持久会话、引导／排队、任务结果、手动保持在线。

**软件及固件构建已通过，PP 真机体验待验收。** 不等于已验证麦克风、扬声器、按键、
休眠、续航或两小时稳定性；正式使用前需配合验收。

需要 PA 0.4.34 或兼容版本，启用 speech_io、aliyun_speech、ai_passport，
配置北京地域百炼语音服务与设备 WSS 接入。固件不保存模型供应商 Key。
这不是无需服务器的离线语音助手，也不包含 PPDemo 质检菜单。

安装后在本网站打开 [PA 终端配置](/pp-setup.html)，使用 Windows Chrome／Edge、
可信 HTTPS 和 USB 数据线，导入 PA 后台生成的配对 JSON、公开 CA，填写 2.4 GHz Wi-Fi。
配对材料 10 分钟有效，临近配置时生成；不要上传到其他网站或发送到聊天。

- 首页按住 OK 超过 200 ms 说话，松开提交；单击停播或打开菜单，双击切换引导／排队。
- 上下翻页；菜单提供继续听、任务结果、取消当前执行、音量、网络与休眠设置。
- 默认空闲 120 秒休眠；桌面使用可手动保持在线，当前没有自动充电状态检测。
- 更新不整片擦除、不写 NVS。恢复出厂是配置页中的独立确认操作，不会删除服务器任务。
- 不支持唤醒词、常开麦克风、全双工、图片显示或 OTA。

先核对目标 ESP32-C3、8 MB Flash 和镜像校验再刷写；不要把安装成功当作硬件验收通过。
