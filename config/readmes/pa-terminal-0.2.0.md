# PA-Terminal 0.2.0

日常使用版本。已完成软件、构建与本次集中硬件功能测试；不代表长期稳定性和全部场景已验收。剩余问题通过日常使用反馈迭代。

## 使用

- 配套 PA 0.4.35、AI Passport 插件 0.3.0，使用协议 2。
- 业务连接 PA 的 HTTP/WS 8047 端口；HTTPS 9443 仅用于浏览器安装固件。
- 新设备开机按屏幕提示连接热点，设置初始 Wi-Fi 和 PA 地址；联网后，在 PA 后台输入设备显示的八位配对码。设置和多个有序 Wi-Fi 配置通过 PA 后台同步。
- 每台 PP 使用独立持久会话，不与 Web 混用；对话模型使用 PA 当前主对话配置。
- 长按 OK 讲话，松开发送；播报时上下调音量、短按 OK 停声。双击 OK 切换引导／排队；长按上回主页。菜单可查看任务消息和设置。
- 最近聊天文字与缩略图使用有界 Flash 缓存，离线可查看最近记录；独立分区 512 KiB，实际数据预算 256 KiB，并非无限历史离线保存。
- 当前已刷入本版的设备无需重复安装。

## 更新注意

按镜像清单校验并写入引导程序、分区表和应用，不整片擦除，不写 NVS。新缓存分区由本版本管理；原有 Wi-Fi 保留。旧协议设备首次连接新版 PA 需要重新配对。刷写不等于业务已连接，以设备和 PA 后台状态为准。

## 已知边界

服务重启后的重连偶有偏慢；更长时间的连续运行及复杂网络场景尚未完成完整稳定性验收。音频服务、模型和任务仍受 PA 现有用量及权限配置约束。

固件与公开依赖许可证随包提供；不包含设备凭据或私有配置。
