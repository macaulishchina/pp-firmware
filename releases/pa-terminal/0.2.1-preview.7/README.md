# PA-Terminal 0.2.1-preview.7

在固件中心选择此版本，通过 USB 更新。沿用 preview.6 的分区布局，安装包不含配置分区镜像，更新时保留已保存的 Wi-Fi、配对和设备设置。请勿选择整片擦除或恢复出厂。

本版修复了 OK 手势跨页面误触、返回设置时焦点丢失、任务列表加载状态和退出配网热点后重新接入原 Wi-Fi 的问题。网络诊断会显示更完整的连接状态，语音转写等待也有明确提示。

已在 PassportSim 验证固件启动、按键导航和离线维护，并通过隔离的在线任务回归。实机 Wi-Fi、录放音和深睡唤醒待验收。

## 刷机后验证

1. 冷启动后确认自动接入原 Wi-Fi 和 PA，原配对与显示设置仍在。
2. 从设备维护进入重新配网，返回后确认恢复原连接。单击或快速连按 OK，检查不会误触下一页操作，退出子页后仍停在原菜单项。
3. 录音并播放回复，按 OK 停播后再次录音。播放时立即打开任务列表，确认加载状态正常，能查看任务正文并返回。
4. 从设置进入休眠，确认设备保持休眠，按键可唤醒，并且唤醒用的按键不会触发页面操作。
