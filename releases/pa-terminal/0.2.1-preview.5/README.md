# PA-Terminal 0.2.1-preview.5

本版修复了配对被拒后无法进入设置，以及开机短暂闪现 `Text` 的问题。通过固件中心用 USB 更新即可保留已保存的 Wi-Fi、配对信息和设备设置。固件构建、协议集成和模拟器按键流程已通过，真机验收待完成。

## 配对被拒时怎样恢复

1. 在连接提示页短按 **OK** 进入设置，打开 **网络状态** 查看 Wi-Fi 和 PA 的连接情况。401 表示身份验证失败，403 表示接入被拒。
2. 要沿用现有身份再试一次，选择 **设备维护 → 重试连接**。
3. 如果已在 PA 后台确认撤销旧配对，在拒绝提示页按 **下键** 打开 **重新配对**。设备默认选中取消。用上下键切换到确认，再按 **OK**，设备会保留 Wi-Fi 和本地设置，更换身份并重启。
4. 在 **PA 配置后台 → 插件设置 → AI Passport → 设备 → 配对新设备** 输入屏幕上的八位码，绑定新会话。

首次使用时，手机连接屏幕显示的热点，打开 `http://192.168.4.1` 填写 2.4 GHz Wi-Fi。固件内置 PA 外网地址和对应的公开 CA。
