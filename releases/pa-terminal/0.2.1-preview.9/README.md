# PA-Terminal 0.2.1-preview.9

在固件中心选择此版本，通过 USB 安装。普通更新保留原 Wi-Fi、PA 配对和设备设置。请保留设备配置，勿选择整片擦除或恢复出厂。

本版修复按住 OK 录音约一秒即提示缓冲已满的问题。配套 PA 支持终端在等待录音就绪回执时发送带本轮标识的音频，保留开头。终端合并音频小包，减少发送次数。若语音通道长时间未就绪或传输跟不上，终端显示具体原因并取消本次录音。

PassportSim 使用本版固件和配套 PA 验证了延迟回执、提前松手、慢速接收和断线重录，语音识别和模型回复使用合成服务。

## 刷机后验证

1. 确认版本为 `0.2.1-preview.9`，设备自动连接原 Wi-Fi 和 PA。
2. 按住 OK 分别录约 1 秒、3 秒、10 秒。每次说不同的开头和结尾，松开后检查转写与回复。
3. 在回复播报期间短按 OK 停播，再长按 OK 说下一句，确认可以继续录音。
4. 如果出现失败，记下时间和屏幕上的完整提示，再录一句，确认可以重录。

真实麦克风、无线环境和线上语音识别仍按上述步骤验收。
