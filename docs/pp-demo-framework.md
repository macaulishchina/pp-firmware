# PP 交互演示底座

这是固定维护的 **PC 浏览器演示底座**，用于讨论 AI Passport 的界面与操作需求。
入口为固件网站 `/pp-demo/`，当前交付 PA 语音终端场景。新增场景继续沿用同一外壳、
屏幕、按键和生命周期，不复制一套新演示项目，不增加另一套 PA 插件机制。

它不申请麦克风、串口或设备权限，不访问 PA、模型或语音服务。模拟成功不等于固件
已实现，也不构成真机验收。录音文字、计时、播报动效和任务结果均为演示数据。

## 目录与职责

```text
public/pp-demo/
├── index.html                 # PC 演示工作台，唯一浏览器入口
├── boot.js                    # 启动边界，配置或资源错误显示可读诊断
├── demo.css                   # PC 页面布局，不做移动端适配
├── demo.js                    # 场景工作台装配、呈现与模拟时钟
├── scenarios.js               # 场景唯一声明源：说明、输入、回复和可选流程
├── model.js                   # 不依赖 DOM、网络或实际计时器的交互状态
├── core/
│   ├── profile.js             # PP 屏幕尺寸、手势、演示延迟和分页参数
│   ├── catalog.js             # 场景声明校验、稳定标识、冲突检查
│   ├── device-shell.js        # 透明机身、240×320 比例屏幕和三枚侧键
│   ├── device.css             # 共用设备与屏幕样式
│   ├── status.js              # 时间、Wi-Fi 名称与强度、电量、PA 断链呈现
│   └── keys.js                # 鼠标／PC 键盘输入、失焦取消与清理
├── passport-front.png         # FoloToy 外观素材
└── FoloToy-LICENSE.txt         # 素材来源许可
```

默认一个页面一个模拟设备。外壳组件返回屏幕及按键句柄；输入适配器接受显式回调，
返回清理函数。状态模型通过构造参数接受场景目录，可以独立执行契约测试。
通用模块不访问 PA，不导入固件代码；场景文件不负责按键、屏幕几何或业务执行。

## 快速增加功能演示

对话、长结果、澄清或后台报告类需求，只向 `scenarios.js` 加入一项：

```js
{
  id: 'travel',
  title: '出行清单',
  description: '整理信息，稍后查看',
  symbol: '↗',
  prompt: '帮我整理明天的出行清单。',
  reply: '已经交给后台整理，可以继续聊天。',
  background: {
    title: '清单已整理',
    body: '证件、钥匙和水杯。这是演示结果，没有创建真实任务。',
  },
}
```

场景选择器、输入预览、完整文本分页、报告呈现自动使用这份声明，不需要修改
HTML 或在状态模型中增加 `if (scenario === 'travel')`。

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定标识，小写字母开头，仅小写字母、数字和连字符，最长 48 字符 |
| `title / description / symbol` | 工作台场景选择器的显示内容 |
| `prompt / reply` | 这次模拟输入与确定回复；均为非空文字 |
| `longPlayback` | 可选；使用较长的模拟播报时间，全文始终保留 |
| `clarification.prompt / reply` | 可选；下一次补充输入及补充后回复，初次 `reply` 用来追问 |
| `background.title / body` | 可选；后台完成后生成的报告，由工作台按钮模拟结果到达 |

声明加载时统一校验，重复 ID 和不完整配置明确报错。文字经转义后显示。
目录顺序决定界面顺序，第一个场景为初始场景。

### 顶部状态

顶部左侧显示时间，右侧 Wi-Fi 图标紧邻电池左侧，名称只在连接详情显示。电量数字放在电池内部，不带百分号。Wi-Fi 信号按
RSSI 映射强／中／弱，图标使用弧线，不使用手机信号格；这些分档是展示约定，不是网速。
菜单的连接详情保留完整名称及 RSSI。Wi-Fi 连上但 PA
不可达时，额外显示异常标记，不把后台断线误显示成 Wi-Fi 断线。时间未同步时显示
`--:--`，低电量突出显示；没有可靠硬件检测前不展示充电图标。

引导／排队只用右下角同一个位置的插入箭头／沙漏表示，与页码或计时保持间隔，分别表达补充当前执行和等待处理，双击 OK 切换；
设备屏幕不显示昵称或独立的模式文字行。普通回复和播报直接显示正文，播报状态
收进底部操作提示与细进度条，不另加“助手的回复”等标题。收紧上下间距并扩大
分页容量；浏览器验收检查每页正文完整可见，不能以裁切文字换取紧凑布局。

右侧顶部状态面板可模拟名称、信号、PA 连通性、电量和时间同步。所有值仍为演示输入，
不查询浏览器电脑或 PP 的实际网络；真实固件后续可接 ESP-IDF 的 `esp_wifi_sta_get_ap_info()`。

已确认业务入口约定：PP 业务复用 PA `8047`，`9443` 仅用于固件网站。非必要不使用
HTTPS；浏览器 USB 等明确要求的场景保留。演示中的连接详情反映这个目标约定，
不代表本次 UI 修改已经切换设备固件或现场业务链路。

新增分页、菜单、连接状态以外的交互类型时，先确定状态转换，再扩展 `model.js`
中的公共动作及 `demo.js` 中对应呈现。需求正文继续留在场景声明，避免将具体功能
名称写进按键、外壳或通用状态分支。无需为假设中的未来需求建立动态插件加载器。

## 固定的交互约束

- 按住 OK 使用模拟采集；松开立即退出录音，之后才等待最终转写。
- 短按在播放时立即停播；平时打开菜单。双击只切换引导／排队，不提交输入。
- 长按上约650ms回形象主页，鼠标及键盘均支持；释放不会再次触发翻页。主页不取消已接受工作，迟到回复不会抢页。
- 根菜单为任务消息、音量、取消当前执行、设置、返回主页；设置和设备维护各最多5项，均有返回项。
- 任务详情有蓝色“任务报告”标记，OK返回列表；列表有返回菜单。空输入只保留形象和一条提示。
- 唤醒手势只唤醒，不同时开启录音。窗口失焦或指针中断时丢弃正在采集的输入。
- 录音、识别和模拟执行各有版本；取消或切换场景后，迟到回调不能覆盖新状态。
- 识别失败没有执行副作用；播放失败或断网不重做已接受的任务。
- 引导使旧回复版本失效；排队保留当前执行，之后依次处理。
- 本页菜单、后台报告和翻页共用状态模型；完整正文不会因分页被截断丢失。
- 离线和休眠不删除已接受的模拟任务，恢复不连续补播、不自动重做。
- 浏览器仅保存输入模式、音量和保持在线偏好，不保存对话、凭据或设备数据。

`profile.js` 的时间是供体验调整的**演示参数**，不是 ESP-IDF 或 PA 配置，也不是性能
承诺。不能将浏览器动效延迟当成语音服务和硬件已经达到的性能。

待机正文使用结合用户多角度照片生成的狸花猫形象 `cat-companion-v2.png`，保留圆厚脸颊、
小耳朵、短脖子、壮实体型、灰棕狸花毛色、黄绿色眼睛、额头 M 纹与白下巴；
形象放大约 20%；idle 以脚底为锚，只保留轻微呼吸与停顿，配合间歇短眨眼及偶尔双眨。
不使用左右旋转、整体摇晃或弹跳来制造表现力。收音时缩至原先接近的尺寸，保留输入空间。
`cat-companion-blink.png` 是保持同姿势的闭眼帧，仅局部混合眼周，避免身体与花纹闪变。
不显示问候文案。之前的图像保留为历史素材。
底部分隔线与操作提示始终保留。原图仅供网页演示，固件接入时需转换为小尺寸资源，不能直接解码原尺寸图片。
长按后图像平滑缩小、上移，让出下方空间逐字呈现输入转写；同一场景 DOM 沿用，
避免重建导致动画跳变。松开后保留已说内容，识别与处理状态放在底部。
松开后的流程为停止收音、确认转写、等待回复、逐字生成及模拟播报；输入区以“你说的”
标记，回复区使用紧凑的“↳ 回复”与生成／播报状态，不重复显示昵称或整段用户输入。
回复速度由 `simulation.responseCharactersPerSecond` 控制；长回复生成时跟随最新页，
用户按上下键后停止自动续页，完成后保留当前页。生成仍属于活动执行，支持引导、排队及取消，
旧版本的后续文字不再交付。此过程仍为本地模拟，不代表真实模型流速或音频播放效果。
浏览历史或菜单时，后台生成事件不重复重建相同屏幕内容，避免反复触发入场动画造成闪烁。
文字与播报分别推进：逐字生成时将已闭合句子加入播报队列，首句就绪即开始模拟播报，
不等待全文完成；无句末标点的尾段仅在生成结束后入队。自动播报保留约 200 字的完整句，
超出部分只保留文字。按下 OK 立即结束本次播报并清空待播音频；同一回复后续句子不再播报。
句段播报进度与生成状态分别显示，生成完成不重置播报；排队输入等待当前播报完成或被停止。
没有暂停、继续听或重播入口；终止播报不终止文字生成或任务执行。
播报中上下键优先调整音量，每次 5，范围 0—100，不翻页也不停播；结束播报后恢复浏览对话。
首行 Wi-Fi 左侧显示喇叭图标，按静音、低、中、高音量变化；调节时出现 1.4 秒的小音量条。
调节只更新状态图标和音量条节点，浏览器偏好延迟合并保存，不因按键重建正文或改变生成进度。
此处仍为音量交互模拟，不调用真实硬件；正式固件可复用 BSP 音量接口。
图像由音量控制轻微缩放和光晕明暗；录音计时只更新图像、文字和计时节点，不重建整屏。
`core/voice.js` 接受归一化音量；当前由模拟语音／静音包络驱动，不采集麦克风。
真机采用已有 PCM 帧抽取少量采样点、计算绝对值均值并做一阶平滑的方案，
约 10—15 Hz 更新音量显示即可；不额外开启采集链路，不做 FFT 或频谱识别。

## 开发、验证与发布

### 热点配网、配对与云控演示

右侧“配网与 PA 云控”保持为本地模拟控制面板，默认仍可直接体验已配对的聊天。
点击“模拟首次开机”后设备只显示热点名称、密码和配置地址；在右侧模拟手机页面填写 Wi-Fi
与 PA 业务地址（默认 HTTP 8047），提交后模拟连接，成功显示有效期 10 分钟的 8 位一次性码。
在模拟 PA 后台输入屏幕数字确认绑定；输入错误、过期或离线时拒绝，不上传配对文件。
手机页面密码字段提交后清空，完全不访问真实热点、不保存或发送密码。

设备配置保存为单独的模拟远端版本，重载才应用；菜单提供“重载配置”，右侧也可触发。
收音、执行、生成或播报中等待空闲应用，断网保留本地值，重连同步，不重启或重新执行任务。
可体验音量、输入模式、简短／完整／关闭播报、电源策略、休眠时间、亮度、字号、语速和离线历史开关。
缓存条数与字节上限留在 Demo 内部，不作为普通配置选项；页面只展示用量及演示参考说明。
简短模式约 200 字的完整句阈值仍只是演示参数，余下查看文字；完整模式不受该演示长度阈值限制。
全部范围与容量未代表真机验收结论，正式值以实际硬件、剩余内存和稳定性测量为准。
音色仅展示配置形态，不模拟真实音色变换。
后台支持 1—5 套 Wi-Fi 名称／密码，按顺序排列，可上移、下移或移除；每条可设置模拟连接成功或失败。
同步有变更的网络配置后，设备在空闲点按顺序尝试，某套成功立即结束；一轮全部失败后从第一套重试，
同一流程最多 3 轮。全部失败后保留配置与配对，不循环启动新一轮；OK 明确重试，或下键进入重新配网确认。
模拟掉线也使用相同的有界连接流程，成功后维持当前网络，不因为更高优先级网络存在而持续切换。
屏幕显示轮次、网络序号及当前名称，右侧展开“本次 Wi-Fi 连接过程”查看尝试记录；不记录密码。
失败／可连接选项是本地环境模拟，离线时也可改变以演示网络恢复，不代表真实 Wi-Fi 校验。
网络密码仅存在本页内存，刷新重置，不发送、不持久化。本轮不调用设备射频或真实 PA 同步接口。
供应商 API Key 不进入设备；原 USB 配置网页及正式固件本轮不修改，新的流程仅在 Demo 演示。
菜单提供重新配网和恢复出厂确认，后者清除模拟本地缓存、绑定及本地偏好，不删除模拟 PA 历史；
后台撤销绑定后重新显示配对码。模拟服务不可达可在首次配网页勾选，并通过右侧网络控制恢复。
`core/provisioning.js` 管理演示配对状态和配置版本，不是正式权限或配置实现。

### 历史查看演示

直接按上下键浏览聊天时间线：先翻当前回复正文，到边界后继续查看当前输入及更早／更新的
对话；按 OK 返回最新对话。不提供独立历史菜单或目录，沿用回复的文字布局，标记“你说的／回复”
及缓存来源，不显示猫形象。预置合成历史，完成的新对话也加入演示历史。
`core/history.js` 将模拟服务端与设备缓存分开：按游标逐段读取选中的轮次，不预取整个会话；
设备缓存最多 3 条、4 KiB，按最近访问淘汰，超大单条不进入缓存。字节数按 UTF-8 JSON 计。
正文分页用于屏幕显示；当前固定合成记录较小，真实大结果仍需服务端正文分页接口。
离线命中缓存可正常查看；未缓存内容提示联网后按上键重试，下键或 OK 返回最新对话。
右侧可清空本地缓存并模拟断网，对比命中、读取等待和淘汰，不删除模拟服务端历史。
全部状态仅在本页内存中，刷新重置；服务端替身最多保留 64 条用于演示，不代表正式保留策略。
没有真实历史接口、音频缓存或模型请求，查看历史也不修改执行内容或模型上下文。

## 当前终端演示补齐

- `image`场景声明本地`image: {src, alt}`缩略图，正文和图片在同一上下翻页路径中；
  `core/history.js`只缓存图片引用，不把图片二进制混入文字缓存。
- `core/pagination.js`按保守的整行预算处理CJK、ASCII、换行与空行；不再单纯按字符总数
  把包含多个段落的页面挤到显示区域外。该预算是Demo参考，固件使用实际字宽和字高。
- 达到60秒先停收音并完成模拟识别，再进入默认丢弃的确认菜单；可查看全文或明确发送。
  右侧“模拟录音达到60秒”仅供快速演示，不用真实等待一分钟；没有设备或供应商调用。
- 队列验收需要等当前文字和已开始的播报交付，或显式停播；不能把模型生成结束直接当作
  扬声器播放结束。短按仍是永久结束本条声音，没有继续听入口。
